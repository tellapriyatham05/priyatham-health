# Jarvis — Voice Command Cheat Sheet

**How every command works:** say **"Jarvis"**, then the command, in one breath.

> 🗣️ *"Jarvis, open YouTube"*

After a command, you have **8 seconds** to say another one **without** "Jarvis" first.
You can also join commands with **"and"** / **"then"**:

> 🗣️ *"Jarvis, open YouTube and search lofi music"*

Words like *please*, *can you*, *for me*, *now* are ignored, so talk naturally.
Every example below starts with "Jarvis, …" (left out to keep the tables short).

## 1. Talking to Jarvis

| Say | What happens |
|---|---|
| **Jarvis** *(pause)* … **open Chrome** | Saying just "Jarvis" wakes it; you then have 8 seconds for the command |
| **Jarvis, open Chrome** | Wake word and command together (fastest) |
| *(within 8 s)* **next tab** | Follow-up command, no "Jarvis" needed |
| **cancel** · **never mind** · **no** | Stop / do nothing |
| **help** · **what can you do** | Shows a short list of commands |
| **what time is it** · **what's the date** | Tells you the time and date |

## 2. Open apps, folders and settings

Jarvis knows **every app in your Start menu** by name.

| Say | Opens |
|---|---|
| **open Chrome** · **launch Spotify** · **start Notepad** | Any Start-menu app |
| **open VS Code** · **open DaVinci** · **open Word** | Short names work too |
| **open File Explorer** · **open my files** | File Explorer |
| **open Downloads** / **Documents** / **Desktop** / **Pictures** / **Music** / **Videos** | That folder |
| **open This PC** · **open Recycle Bin** | This PC / Recycle Bin |
| **open Settings** | Windows Settings |
| **open Wi-Fi settings** / **Bluetooth settings** / **display settings** / **sound settings** | That settings page |
| **open wallpaper settings** · **open Windows Update** · **open apps settings** | That settings page |
| **open Task Manager** · **open Control Panel** | Those tools |
| **open terminal** · **open command prompt** · **open PowerShell** | Command windows |
| **open Calculator** · **open Paint** · **open Snipping Tool** | Those apps |
| **switch to Chrome** · **bring up Spotify** · **go back to Word** | Brings an open app to the front |
| **close Spotify** · **quit Notepad** | Closes that app |

## 6. Typing and keyboard keys

| Say | What happens |
|---|---|
| **type hello how are you** | Types the words (Jarvis re-listens carefully to get them exact) |
| **type good morning and enter** | Types, then presses Enter |
| **enter** · **press enter** · **submit** · **go** | Enter |
| **new line** | Shift + Enter |
| **select all** | Ctrl + A |
| **copy** · **paste** · **cut** | Ctrl + C / V / X |
| **undo** · **redo** | Ctrl + Z / Y |
| **save** · **save this file** | Ctrl + S |
| **delete** | Delete key |
| **delete the last word** | Removes the word before the cursor |
| **clear everything** · **clear the box** | Select all + delete |
| **escape** · **backspace** · **space** | That key |
| **up** · **down** · **left** · **right** (arrow) | Arrow keys |
| **page up** · **page down** | Page keys |
| **press ctrl shift t** · **press alt f4** · **press windows** · **press f5** | Any key combo you name |

Key names you can use: enter, escape, tab, backspace, delete, space, up / down / left / right,
home, end, page up, page down, control, shift, alt, windows, print screen, insert, caps lock,
F1–F12, and any single letter or number.

## 7. Dictation

| Say | What happens |
|---|---|
| **start dictation** · **dictation** · **type what I say** | Everything you say now gets typed |
| **comma** · **full stop** / **period** · **question mark** · **exclamation mark** · **colon** · **semicolon** | Types , . ? ! : ; |
| **new line** · **new paragraph** | Line break / blank line |
| **stop dictation** · **stop** · **done** | Ends dictation |

No "Jarvis" is needed while dictating. Dictation also stops by itself after **20 seconds** of silence.

## 8. Clicking things on screen

| Say | What happens |
|---|---|
| **click Subscribe** · **click the Sign in button** · **press Next** | Finds that button/link **by its name** and clicks it |
| **double click Recycle Bin** · **right click Chrome** | Double / right click by name |
| **show numbers** | Puts a number on every button and link on screen |
| **7** · **click 7** · **number seven** | Clicks item 7 *(while numbers are showing)* |
| **double click 4** · **right click 12** | Double / right click a numbered item |
| **type into 3 hello** | Clicks box 3 and types "hello" |
| **hide numbers** | Removes the numbers *(they also go away after 30 s)* |

If several things have the same name, Jarvis numbers them and asks you to pick one.

## 13. Timers and reminders

| Say | What happens |
|---|---|
| **timer 5 minutes** · **set a timer for an hour and a half** · **10 minute timer** | Starts a timer |
| **remind me in 20 minutes to call mom** | Reminder after a time |
| **remind me to drink water in half an hour** | Same, other word order |
| **remind me at 6:30 pm to go to the gym** | Reminder at a clock time |
| **remind me tomorrow at 9 am to send the report** | Tomorrow |
| **what are my timers** · **how much time is left** | Lists them |
| **cancel the timer** · **cancel all reminders** · **cancel the reminder about mom** | Cancels |

Times Jarvis understands: *90 seconds, 5 minutes, twenty five minutes, an hour, half an hour,
a quarter of an hour, 1 hour 30 minutes, 6:30 pm, 9 in the morning, noon, midnight, tonight, tomorrow.*
Timers survive a restart; reminders missed while the PC was off (in the last 12 hours) are told to you when Jarvis starts.

## 17. Lock, sleep, restart, shut down

| Say | What happens |
|---|---|
| **lock** · **lock the PC** | Locks right away |
| **sleep** · **put the PC to sleep** | Sleep |
| **restart** · **restart the computer** | Asks *"Are you sure?"* → say **yes** → restarts in 10 s |
| **shut down** · **turn off the computer** | Asks → **yes** → shuts down in 10 s |
| **sign out** · **log out** | Asks → **yes** → signs out |
| **cancel shutdown** · **stop the restart** | Stops a restart/shutdown during those 10 s |

If you don't say "yes" within 10 seconds, nothing happens.

## 18. Jarvis himself

| Say | What happens |
|---|---|
| **hello** · **how are you** · **who are you** · **thank you** | A short reply |
| **battery** · **system status** | Battery, CPU and memory |
| **quit** · **exit** · **bye** · **hide** · **go away** | Iron Man flies off the screen but **keeps listening**. Say "Jarvis" to call him back |
| **come back** · **come here** · **show yourself** | He flies back in |
| **quit Jarvis completely** | Closes JARVIS (it starts again at your next sign-in) |
| **stop listening** · **go quiet** · **sleep Jarvis** | Jarvis stops listening (press **Ctrl + Alt + J** or click him to resume) |
| **help** · **what can I say** | Command list on screen |

## 19. Keyboard shortcuts and mouse

| Shortcut / action | What it does |
|---|---|
| **Ctrl + Alt + J** | Same as saying "Jarvis" — listens for a command now. *(If another app already uses it: **Ctrl + Shift + Alt + J**, else **F9**; the menu shows which one you have.)* |
| **Click Iron Man** | Same as saying "Jarvis" |
| **Right-click Iron Man** | Opens Jarvis's menu (voice, size, your picture, …) |
| **Drag Iron Man** | Move his corner anywhere on screen (he remembers the spot) |
| **Jarvis tray icon** (near the clock) | Same menu as right-clicking |
| **Ctrl + S** in the commands editor | Saves your commands |
