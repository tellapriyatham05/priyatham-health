JARVIS for Windows
==================

1. Unzip this folder anywhere (for example Documents\JARVIS) and double-click JARVIS.exe.
   If Windows SmartScreen says "Windows protected your PC", click "More info" -> "Run anyway".
2. The settings window opens and a blue icon appears in the system tray (bottom right; click ^ if hidden).
3. Allow the microphone if Windows asks (Settings -> Privacy -> Microphone -> Let desktop apps access your microphone).
4. Settings -> Character -> "Choose image..." and pick your Iron Man picture. JARVIS removes the background.
5. For the Indian English male voice: Windows Settings -> Time & language -> Speech -> Add voices -> English (India),
   then restart JARVIS.
6. Say "Jarvis" (or "Hey Jarvis"), click the character, or press Ctrl+Alt+J. He flies in and stays in the corner.
   Say "Jarvis, hide" to send him away. Drag him to move him; right-click him for the menu.

Try: "Jarvis, open VS Code" · "remember that MediaAI is my main project" · "open my main project" · "coding mode"
     "volume 40" · "wifi off" · "play lofi music on YouTube" · "system status" · "remind me in 20 minutes to stretch"
     "set a timer for 25 minutes" · "lock my laptop" · "type hello world" · "what can you do" · "Jarvis, hide"

Everything runs on this laptop: no account, no cloud, no API keys.
